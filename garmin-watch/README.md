# Garmin Companion

Projet Connect IQ compagnon pour la montre Garmin.

Objectif :
- recevoir la question courante depuis l'application Android
- afficher les 4 reponses sur la montre
- renvoyer la reponse choisie vers le telephone

Fichiers principaux :
- `manifest.xml`
- `monkey.jungle`
- `source/RevisionExpressGarminApp.mc`
- `source/RevisionExpressGarminView.mc`

Pour compiler ce projet, il faut installer le SDK Connect IQ depuis Garmin Developers puis ouvrir ce dossier dans Monkey C / VS Code avec les outils Garmin.
